# Suppress Wake Notification Spam

Windhawk mod for Windows 11 that stops queued notifications from spamming banners and sounds when the PC wakes or the monitor turns back on.

It temporarily enables Do Not Disturb while the display is off, Windows is locked, or the PC is suspended, then restores the previous DND state shortly after you return.

Notifications are not deleted; they remain in Notification Center.

The mod does not read or log notification contents.

## Installation

Create a local mod in Windhawk and paste in `suppress-wake-notification-spam.wh.cpp`.

Tested on Windows 11.
