# Changelog

## 1.0.0 - 2026-10-03

- First public release.
- Suppresses wake/unlock notification banner and sound backlogs by temporarily enabling Windows Do Not Disturb while the user is away.
- Preserves and restores the user's previous DND state.
- Adds display-off, lock, and suspend triggers with a configurable restore delay.
- Adds persistent recovery state for abnormal Windhawk/helper termination.
- Adds privacy-preserving diagnostic logging that does not inspect notification contents.
